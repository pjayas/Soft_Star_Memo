SoftStar 오프라인/PWA 배포 안내

포함 파일
- 1103_수정본.html: 수정된 스터디 보드
- sw.js: 오프라인 화면 및 정적 리소스 캐시
- manifest.webmanifest: 홈 화면 앱 설정
- icon-192.png / icon-512.png: 앱 아이콘

설치 및 사용
1. 모든 파일을 같은 폴더에 업로드하세요.
2. HTTPS가 적용된 웹 호스팅에 올려야 합니다. 로컬 파일(file://)로 열면 PWA 설치/서비스 워커가 작동하지 않습니다.
3. Safari에서 https://사이트주소/1103_수정본.html 을 엽니다.
4. 공유 버튼 → 홈 화면에 추가를 선택합니다.
5. 최초 1회 온라인으로 접속해 앱 화면과 필요한 리소스를 캐시하세요.
6. 이후 이미 불러온 앱 화면을 오프라인에서도 열 수 있습니다.

오프라인 범위
- 이미 로그인한 기기에서 이전에 동기화된 Firestore 자료는 IndexedDB 캐시를 통해 오프라인 열람을 지원합니다.
- 새 계정 가입/로그인, 서버에 없는 최신 자료 내려받기, 다른 사용자와 실시간 동기화는 인터넷 연결이 필요합니다.
- 오프라인에서 일부 복합 작업(예: 분야 설정 트랜잭션, 학습 기록 저장)은 제한될 수 있습니다.
- 처음 방문한 상태에서 인터넷 없이 앱을 여는 것은 불가능합니다. 먼저 온라인 상태에서 한 번 열어 캐시해야 합니다.
